# 34-theme reference card

The 34 Clifton StrengthsFinder talent themes, with a one-line paraphrased essence of
each theme's core drive. The theme set is stable across both sources and across
v1.0 / v2.0. Essences are distilled, not quoted.

**Use with the blind-spot rule (below):** whenever a theme is interpreted, name its
over-expression risk alongside the benefit — every dominant theme is double-edged
(P-005, CL-027).

## Theme essences

| Theme | Core drive (essence) |
|-------|----------------------|
| Achiever | A constant inner drive; needs to accomplish something tangible every day. |
| Activator | Converts thought into action; impatient to start — believes only action makes things happen. |
| Adaptability | Lives in the present; flexes to the moment rather than a fixed plan. |
| Analytical | Demands proof and underlying logic; tests claims before accepting them. |
| Arranger | Orchestrates many moving parts to find the most productive configuration. |
| Belief | Driven by enduring core values that give work purpose and direction. |
| Command | Takes charge; comfortable imposing a view and confronting directly. |
| Communication | Explains, describes, and brings ideas to life through words. |
| Competition | Measures progress against others; driven to win and outperform. |
| Connectedness | Sees links between all things; believes events have meaning and we are part of something larger. |
| Consistency | Values fairness through uniform rules; treats everyone the same. |
| Context | Understands the present by studying the past and how things began. |
| Deliberative | Careful and vigilant; anticipates risk before acting. |
| Developer | Sees and cultivates potential in others; energised by their growth. |
| Discipline | Needs order, structure, routine, and predictability. |
| Empathy | Senses and feels others' emotions as if they were their own. |
| Focus | Sets a direction and filters everything against the goal. |
| Futuristic | Energised by visions of what could be; inspired by the future. |
| Harmony | Seeks consensus and common ground; steers away from conflict. |
| Ideation | Fascinated by ideas and the connections between concepts. |
| Includer | Widens the circle to bring others in; dislikes anyone being left out. |
| Individualization | Attuned to each person's unique qualities; rejects generic "types". |
| Input | Collects and stores information, things, and knowledge. |
| Intellection | Drawn to thinking and mental activity; introspective. |
| Learner | Energised by the process of learning itself, whatever the subject. |
| Maximizer | Transforms strong into superb; focuses on excellence over fixing weakness. |
| Positivity | Generous with praise and enthusiasm; brings lightness and energy. |
| Relator | Deepens close, genuine bonds with people already known. |
| Responsibility | Takes psychological ownership of commitments; bound to follow through. |
| Restorative | Energised by solving problems and restoring what is broken. |
| Self-Assurance | Confident in own judgment and ability to deliver; inner compass. |
| Significance | Wants to be recognised and to make a visible, meaningful impact. |
| Strategic | Sees patterns; sorts through clutter to find the best route forward. |
| Woo | Wins others over; enjoys meeting strangers and building rapport quickly. |

## The blind-spot rule (P-005)

Every dominant theme carries a characteristic over-expression risk that must be named
alongside the benefit (CL-027). Presenting a theme as purely positive misrepresents
the framework and can lead the person to over-apply the talent in ways that damage
relationships, ignore context, or reduce effectiveness.

Worked examples from the source:

- **Command** — drives results, but pushed too far can damage relationships.
- **Consistency** — ensures fairness, but pushed too far can fixate on uniform process
  at the expense of the outcome.

For any other theme, derive its blind spot from the over-expression of its own drive
(e.g. the excess, rigidity, or misapplication of the essence above) and name it
explicitly when interpreting.
