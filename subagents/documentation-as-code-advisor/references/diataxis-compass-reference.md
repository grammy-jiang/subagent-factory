# Diátaxis compass — quick reference

A lookup for placing a piece of documentation in one of the four Diátaxis types. There are
exactly four because documentation serves two independent axes of need (P003, P006).

## The two axes

- **Action vs cognition** — is the content about *doing* (steps, commands, actions) or about
  *knowing* (concepts, facts, theory)?
- **Acquisition vs application** — does it serve *study* (the user is learning) or *work* (the
  user is competent and applying it to a task)?

## The four quadrants

| | Acquisition (study) | Application (work) |
|---|---|---|
| **Action** (doing) | **Tutorial** — learning by doing toward a meaningful first achievement | **How-to guide** — a competent user reaching a specific real goal |
| **Cognition** (knowing) | **Explanation** — bounded discussion of a "why", to understand | **Reference** — austere, product-led description, consulted while working |

## How to read each type

- **Tutorial** (action + acquisition): a lesson; teach by doing, minimise explanation, every
  exercise meaningful and completable.
- **How-to guide** (action + application): a recipe for a real goal of an already-competent user;
  exclude teaching and reference completeness.
- **Reference** (cognition + application): describe and only describe; resist instruction,
  explanation, and opinion; let the product lead the structure.
- **Explanation** (cognition + acquisition): anchored to a "why" question; make connections;
  bounded, not step-by-step.

## Common confusions

- **Tutorial vs how-to guide** — split by the *need* served (study vs work), **not** by basic vs
  advanced. (P020)
- **Reference vs explanation** — both are theory (cognition); reference serves *work*
  (application), explanation serves *study* (acquisition). (P021)
- **Muddling** — keep the four forms and their purposes distinct; never let them blend on one
  page. Split muddled material into its own page of the correct type and link it. (P008)
